Task Management REST API

A REST API for managing tasks, supporting task creation, retrieval, updates, and deletion. The project demonstrates HTTP API design, server-side validation, database persistence, and separation of application responsibilities.


Features:
-Create a task.
-Retrieve all tasks.
-Retrieve a task by ID.
-Update a task.
-Delete a task.
-Validate incoming requests.
-Persist task data in a database.
